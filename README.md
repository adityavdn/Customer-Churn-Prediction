# 📊 Customer Churn Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Analytics](https://img.shields.io/badge/Analytics-Churn-red.svg)

## 📖 Overview

General customer churn prediction model applicable across industries. Identifies at-risk customers using behavioral patterns, engagement metrics, and transaction history.

## 🎯 Objectives

- Predict customer churn probability
- Identify churn drivers
- Retention strategy development
- Customer lifetime value analysis

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Usage

```bash
git clone https://github.com/adityavdn/Customer-Churn-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Metrics

- Customer tenure
- Transaction frequency
- Product usage
- Support interactions
